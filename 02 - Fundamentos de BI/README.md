# 📊 Desafio: Analisando dados de um Dashboard de Vendas no Power BI

## 📌 Sobre o desafio

O objetivo foi reproduzir duas páginas de um relatório apresentado durante o módulo e desenvolver uma **terceira página de forma independente**, utilizando os recursos de visualização disponíveis no Power BI.

---

## 🎯 Objetivos do desafio

* Reproduzir páginas de um relatório desenvolvido durante o módulo;
* Praticar a criação e configuração de visuais no Power BI;
* Desenvolver uma página de relatório de forma independente;
* Trabalhar com mapas e gráficos;
* Analisar vendas, unidades vendidas e lucro;
* Organizar a disposição dos elementos no relatório;
* Utilizar campos como dicas de ferramentas (*tooltips*);
* Publicar e compartilhar o relatório.

---

## 📊 Estrutura do relatório

O relatório é composto por três páginas.

### Página 1 e Página 2

As duas primeiras páginas foram reproduzidas a partir do conteúdo apresentado durante o módulo, permitindo colocar em prática os conceitos demonstrados nas aulas.

### Página 3 — Análise desenvolvida

A terceira página foi construída de forma independente, conforme as orientações do desafio.

---
  
## 🛠️ Ferramentas utilizadas

* Power BI Desktop
* Power Query
* GitHub

---

## 🚀 Aprendizados

Este projeto proporcionou a prática dos principais recursos de visualização do Power BI, especialmente na construção de análises utilizando mapas e gráficos.

A criação da terceira página também permitiu exercitar a autonomia na escolha dos visuais, organização das informações e apresentação dos dados de acordo com o contexto da análise.
