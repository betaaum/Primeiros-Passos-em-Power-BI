# 05 - Modelagem de Dados com Power BI

Diretório destinado aos desafios práticos de modelagem dimensional e estruturação analítica do módulo de Power BI.

---

## 📂 Desafios do Módulo

### [Desafio de Projeto 01 — Modelagem Dimensional de Sistema Acadêmico](./Desafio%20de%20Projeto%2001)
- **Foco:** Arquitetura conceitual de modelo dimensional.
- **Escopo:** Conversão de uma base relacional transacional acadêmica para um diagrama em **Star Schema** centrado na atividade docente (`fat_docente`), definindo métricas aditivas, dimensões analíticas e chaves substitutas (*Surrogate Keys*).

### [Desafio de Projeto 02 — Modelagem e Transformação de Dados com DAX](./Desafio%20de%20Projeto%2002)
- **Foco:** Transformação prática de dados no Power Query e desenvolvimento analítico no Power BI Desktop.
- **Escopo:** Reestruturação da base desnormalizada `Financials Sample` em um modelo estrela completo, com tabela de preparação sem carga, agregações estatísticas, criação de tabela calendário dinâmica via **DAX** (`D_Calendario`) e configuração de cardinalidades ($1:*$ e $*:*$).

---

## 🛠️ Tecnologias e Conceitos

- Power BI Desktop (Power Query & DAX Engine)
- Modelagem Dimensional (Star Schema)
