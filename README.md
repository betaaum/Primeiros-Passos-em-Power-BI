# Universia - Primeiros Passos em Power BI 

## Detalhes do bootcamp

Aprenda do zero como usar Power BI com Inteligência Artificial para organizar dados, criar análises e construir dashboards voltados à tomada de decisão, com uma trilha prática que conecta fundamentos de IA, SQL, DAX, modelagem dimensional, storytelling com dados e integração com MySQL e Azure em um único programa. 

Entenda como funcionam Machine Learning, LLMs e IA Generativa para aplicar esses conceitos no seu dia a dia, utilize o NotebookLM para acelerar seus estudos, domine Power BI do zero com KPIs, métricas e visualizações profissionais, crie cálculos com DAX, estruture dados com Star Schema e modelagem dimensional, integre fontes com MySQL e Azure em cenários corporativos, e desenvolva um Dashboard Gerencial para Tomada de Decisões com Power BI como projeto final, transformando dados brutos em informações estratégicas, claras e visuais.
