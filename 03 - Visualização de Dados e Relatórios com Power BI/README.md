# 📊 Desafio: Criando um relatório de lucro detalhado no Power BI

## 📌 Sobre o desafio

O objetivo foi criar um relatório mais elaborado utilizando a sample **Financials**, disponibilizada pela Microsoft, aplicando os recursos apresentados durante o módulo.

O desafio consistiu na criação de uma segunda página para o relatório, explorando diferentes recursos de visualização e análise de dados no Power BI.

---

## 🎯 Objetivos do desafio

- Criar a segunda página do relatório;
- Trabalhar com diferentes tipos de visualizações;
- Utilizar uma árvore de decomposição para análise de lucro;
- Trabalhar com hierarquia de datas;
- Criar análises de lucro por produto e segmento;
- Utilizar filtros e segmentadores;
- Explorar recursos de navegação e interação;
- Publicar o relatório no Power BI Service;
- Submeter o projeto através do GitHub.

---

## 📊 Estrutura do relatório

O relatório é composto por duas páginas.

### Página 1 — Relatório de Vendas

A primeira página apresenta uma visão geral dos resultados financeiros, incluindo indicadores de vendas, unidades vendidas, descontos, vendas brutas e COGS.

Também foram utilizados gráficos para análise das vendas por diferentes dimensões.

### Página 2 — Report de Lucro Detalhado

A segunda página foi desenvolvida conforme a proposta do desafio, com foco na análise detalhada do lucro.

Foram utilizados:

- Árvore de decomposição;
- Gráfico Radar;
- Treemap;
- Gráfico de cascata;
- Segmentadores;
- Hierarquia de datas;
- Filtros por ano e país.

A página permite analisar o lucro por **ano, país, produto, segmento e trimestre**.

---

## 🛠️ Ferramentas utilizadas

- Power BI Desktop
- Power BI Service
- GitHub

## 🚀 Aprendizados

Este projeto permitiu aprofundar a utilização dos recursos de visualização e interação do Power BI, especialmente na criação de uma página voltada para análise detalhada.

Também foram praticados recursos como **árvore de decomposição, hierarquia de datas, segmentadores, filtros, navegação e diferentes tipos de gráficos**, ampliando a experiência na construção de relatórios interativos.
